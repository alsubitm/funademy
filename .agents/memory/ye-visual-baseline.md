Use the supplied FunAdemy v9 prototype and preview set as the visual baseline for the public website. Preserve the live application's backend, data model, booking, payments, accounts, learning platform, admin, routes, and real-data behavior rather than importing the reference project wholesale.

**Why:** The v9 files are a design reference, while the current application contains newer production functionality and data that must not be lost during visual restoration.

**How to apply:** New public-facing UI work should remain consistent with v9's bright engineering-lab presentation and responsive behavior. Treat reference-only mock data as visual guidance and keep existing real data and integrations authoritative.
